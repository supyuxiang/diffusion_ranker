# Class-Conditional Scripts

This directory groups class-conditional experiment scripts,
similar to the existing `uncondition/` and `text2image/` layouts.

Main scripts:

- `rollout.py`
- `train.py`
- `val.py`
- `build_ranker_training_data_mc.py`
- `run_build_ranker_training_data.sh`
- `train_pointwise_ranker_by_ratio.sh`
- `run_random_search_with_trained_ranker.sh`
- `pipeline.sh`

Legacy `mid_*` names are removed in this directory.
